## ✨ 核心功能

### 🧠 边缘端真实网页抓取 & AI 深度解析
* **免代理 & 突破 CORS**: 后端基于 Cloudflare Pages Functions 边缘运行时，服务端直接抓取目标网页真实 HTML 内容，提取网页 Meta 标题、官方描述、高清 Favicon 与正文摘要。
* **智能精炼与总结**: 接入 **Google Gemini** 或 **OpenAI / DeepSeek** 兼容模型，彻底告别“凭空脑补”，自动生成 30 字以内的精炼中文介绍。
* **智能推荐分类**: AI 结合您现有的全部分类结构，自动识别网站类型并推荐归属到最匹配的目录。
* **AI 建议标签**: 智能提炼 2~4 个最具代表性的标签候选，一键点击即可收纳。

### 🏷️ 智能标签体系 (Tags)
* **多标签支持**: 支持为每个书签配置专属标签（如 `#开发工具`、`#效率`、`#AI`）。
* **一键交互筛选**: 详细版卡片与简约版卡片均以优雅徽章呈现标签，点击任意标签即可直接触发全站快速检索。
* **全景搜索**: 搜索框输入关键词，同时匹配网站标题、URL、描述、表情符号与关联标签。

### ⭐ 自主表情符号 / 标记 (Emoji Badge)
* **个性化徽标**: 常用网站一键添加 ⭐、🔥、❤️ 或任意自定义 Emoji（如 🚀、💡）。
* **醒目标识**: 标记常驻显示在网站标题右侧，重要网址一目了然。

### 🔒 灵活安全体系 & 永不退出登录
* **永不退出机制**: 登录弹窗与设置中提供「永不退出（直至修改密码）」选项，常用设备无需频繁输密。修改管理密码后自动吊销历史所有凭据。
* **全局访问锁**: 设置访问密码，保护个人私密收藏不被外界窥探。
* **二级目录隐私锁**: 支持对特定私密分类单独加锁，仅在输入目录独立密码后解锁。

### 🎨 优设导航 (UISDC) 风格与极致交互
* **对标优设导航视觉设计**: 全站背景采用温和护眼浅灰底色 (`#f4f5f7` / 暗黑模式 `#0b1120`)，卡片具备轻量悬浮微升效果 (`hover:-translate-y-1`) 与精致柔和弥散阴影。
* **多引擎横向平铺搜索栏**: 顶部集成 UISDC 经典横向外露平铺切换 Tab（站内、百度、Google、Bing、GitHub 等直接点击切换），居中大胶囊搜索框与一键清空。
* **双模式卡片视图**: 支持「简约版」高密度视图与「详情版」丰富信息视图一键切换，配备精致 40×40px 大圆角 Favicon、精简两行说明与标签胶囊。
* **分块渐变指示条**: 各分类段落标头配有专属圆角渐变指示条，层次清晰，信息扫读自然流畅。
* **拖拽灵活排序**: 基于 `@dnd-kit`，支持分类内拖拽自由排序以及热门推荐专区独立排序。
* **右键上下文菜单**: 卡片右键快捷操作：直达编辑、设置表情符号、复制链接、生成二维码、快速删除。
* **数据多重备份**: 支持 JSON 导入导出、标准浏览器书签 HTML 导入导出，以及 WebDAV 云端备份。

## 🚀 部署教程 (免费)

本项目完全托管在 **Cloudflare Pages** + **KV**，永久免服务器费用。

### 方式一：Cloudflare Pages 网页控制台部署 (适合所有人)

1. **Fork 本仓库**：点击本页面右上角 **Fork**，将本项目复制到您的个人 GitHub。
2. **新建 Pages 应用**：
   - 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)。
   - 依次进入 **Workers 和 Pages** -> **创建应用程序** -> **Pages** -> **连接到 Git**。
   - 选择您 Fork 的 `CloudNav` 仓库并点击“开始设置”。
3. **构建配置**：
   - **框架预设 (Framework preset)**：选择 `Vite`（推荐，会自动补全设置）或 `无 (None)`。
   - **构建命令 (Build command)**：`npm run build`
   - **构建输出目录 (Build output directory)**：`dist`
   - **根目录 (Root directory)**：**留空不用填**（留空即代表项目根目录 `/`）。
4. **创建 KV 数据库**：
   - 在 Cloudflare 左侧导航栏点击 **Workers 和 Pages** -> **KV** -> **创建命名空间**。
   - 空间名称填写：`CLOUDNAV_DB`。
5. **绑定 KV 与环境变量**：
   - 进入刚创建的 Pages 项目 -> **设置 (Settings)** -> **函数 (Functions)** -> **KV 命名空间绑定**：
     - **变量名称**：`CLOUDNAV_KV` *(必须完全一致)*
     - **KV 命名空间**：选择刚才创建的 `CLOUDNAV_DB`
   - 进入 **设置 (Settings)** -> **环境变量 (Environment variables)** -> **生产环境 (Production)**：
     - 添加变量名：`PASSWORD`
     - 变量值：设置您的私有管理密码 *(建议高强度密码)*
6. **完成部署**：
   - 点击 **保存**，触发重新部署即可！访问 Cloudflare 分配的 `*.pages.dev` 域名即可立即使用。

### 方式二：使用 Wrangler CLI 极速部署 (开发者推荐)

如果您在本地进行开发，也可以直接通过 Cloudflare 官方 CLI 工具秒级部署：

```bash
# 1. 安装依赖
npm install

# 2. 本地构建
npm run build

# 3. 登录并发布到 Cloudflare Pages
npx wrangler login
npm run deploy
```

## ⚙️ 使用指南

### 1. 配置 AI 智能解析服务
点击页面左下角 **“设置”** -> **“AI 设置”**：
* **AI 提供商**：
  * **Google Gemini**（推荐，响应快速，免费额度充沛）：模型填 `gemini-2.5-flash`。
  * **OpenAI 兼容**（可接入 DeepSeek、Claude、通义千问等）：填入相应的中转 Base URL、API Key 与 Model 名称。
* **生效场景**：
  * **添加/编辑链接**：输入网址后点击 **“AI 深度解析”**，系统通过边缘函数实时抓取该网站内容，AI 自动填写标题、精炼简介、推荐所属分类，并生成建议标签。
  * **全局一键扫描**：在设置面板点击“一键补全所有描述”，AI 将自动扫描并补齐历史空白简介。

### 2. 标签系统使用技巧
* **添加标签**：在添加或编辑弹窗中，输入标签文字后按 **回车 (Enter)** 或 **逗号 (,)** 即可添加；亦可直接点击下方 AI 分析给出的 **“建议标签”** 快速采纳。
* **快速检索**：在网站卡片上直接点击带有 `#` 的标签徽章，即可自动在全站范围过滤展示所有具备该标签的网站。

### 3. 数据备份与安全迁移
* **本地导出**：点击左下角 **“备份与还原”**，可导出全量 JSON 文件或标准浏览器 HTML 书签文件。
* **多端同步**：所有配置与站点数据均存储在 Cloudflare 全球边缘分布式 KV 中，手机、电脑、平板随时随地打开即最新状态。
* **WebDAV 远端备份**：可一键将加密数据推送到 OpenDrive、坚果云或自建 Nextcloud 实例。
