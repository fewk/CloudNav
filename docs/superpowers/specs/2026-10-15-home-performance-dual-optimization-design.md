# 首页 5000+ 海量书签双重极客性能优化设计规范 (Design Spec)

- **日期**：2026-10-15
- **版本**：v2.7.0
- **目标**：彻底化解 5000+ 书签在首页全量挂载导致的 DOM 树膨胀、首屏渲染压力与长页面滚动卡顿，实现首屏瞬间加载与极致丝滑浏览。

---

## 1. 背景与现状分析

在 CloudNav 中，首页全景流将所有分类依次纵向排列展开。当用户导入超过 5000+ 书签时：
1. **DOM 树体量庞大**：尽管外层容器应用了现代 CSS `content-visibility: auto`，但 React 运行时在首屏与每次根状态变更时，仍然会在内存中为全部 5,000+ 个链接卡片创建 Fiber 节点与超 75,000 个真实 DOM 节点，初始挂载与内存占用沉重。
2. **巨型单分类拉长视口**：某些分类导入了数百甚至上千条链接，导致用户向下滚动时单个分类难以见底，进入视口时浏览器需要瞬间计算数百张卡片的排版布局。
3. **锚点定位与交互协调**：需要确保在延迟挂载的机制下，侧边栏点击、子分类按钮点击（`scrollToSection`）依然能精准定位到对应分类，且在拖拽排序模式下无任何功能受限。

---

## 2. 核心架构与方案设计

针对上述痛点，采用**「React 级视口懒加载（Lazy Section Mount） + 超长分类智能折叠展开（Collapsible Category Grid）」**的极客双重架构。

### 2.1 React 级分类视口懒加载 (Lazy Section Mount)

1. **容器级监听**：
   - 提取或增强分类渲染模块，为每个主分类及二级分类独立绑定 `IntersectionObserver`；
   - 设定 `rootMargin: '600px 0px'` 预载缓冲带，用户向下滚动接近分类前 600px，后台自动静默挂载该分类的所有卡片；
   - **首屏保活**：热门推荐专区及前 2 个主分类默认初始立即挂载（`isInitiallyMounted = true`），确保用户进入网站首屏 0 延迟、0 闪烁；
   - **单次挂载常驻（Lazy Mount Once）**：分类进入视口挂载后保留在 DOM 中，避免反复滚进滚出带来的重复重建销毁开销。

2. **锚点跳转与强制保活**：
   - 当用户在侧边栏或二级分类药丸按钮点击跳转（调用 `scrollToSection(targetId)`）时，系统立即将 `targetId` 对应的分类标记为已激活/已挂载（`activeSection` 或 `forcedMountedCategories`），再执行平滑滚动，确保目标容器的高度与 DOM 节点已完全就绪。

### 2.2 超长分类智能折叠与渐进展开 (Collapsible Category Grid)

1. **折叠阈值规约 (`CATEGORY_COLLAPSE_THRESHOLD = 36`)**：
   - 在 2、3、4、6 列响应式网格布局下，36 张卡片刚好整齐排布为 18 行、12 行、9 行或 6 行，高度适中，版面规整；
   - **免折叠场景**：若某分类下的链接数量 $\le 36$，直接全量渲染，不显示任何多余的折叠/展开操作元素；
   - **超量折叠场景**：若链接数量 $> 36$：
     - 初始状态仅渲染前 36 张卡片；
     - 网格底部居中呈现精致的胶囊操作条：`展开全部 (已展示 36 / X 个) ↓`；
     - 点击后无缝展开该分类的剩余全部卡片，按钮文字切换为 `收起 ↑`；
     - 展开状态独立按分类 ID 记录在组件状态中（`expandedCategoryIds`）。

2. **拖拽排序与批量模式兼容**：
   - 当管理员点击分类的「排序」进入拖拽模式（`isSortingMode === cat.id`）或处于批量编辑状态时，强制展开该分类的所有卡片并挂载，保证 `@dnd-kit` 排序与快捷删除无任何死角。

## 3. UI 与交互细节规范

1. **展开/收起按钮样式**：
   - 居中胶囊造型，适配明暗模式：
     - 亮色：`bg-slate-100 hover:bg-slate-200 text-slate-600 border border-slate-200/80`
     - 暗色：`dark:bg-slate-800 dark:hover:bg-slate-700 dark:text-slate-300 dark:border-slate-700/80`
   - 内置 Lucide 图标：展开展示 `ChevronDown`，收起展示 `ChevronUp`；
   - 平滑动画过渡，点击无视觉跳动。

2. **分类空状态与加锁状态**：
   - 保持现有的密码锁逻辑（加锁分类展示密码解锁遮罩，未解锁前跳过内部卡片渲染）；
   - 链接数为 0 时展示轻量「暂无链接」虚线框。

## 4. 性能预期指标

| 指标项 | 优化前 (5000+ 链接) | 优化后 (5000+ 链接) | 提升幅度 |
| :--- | :--- | :--- | :--- |
| **首屏初始 DOM 节点数** | ~75,000+ | ~1,500 ~ 3,000 | **下降 95%+** |
| **首屏 React 实例化耗时** | 800ms ~ 2,500ms | < 30ms | **加速 30~80 倍** |
| **滚动帧率 (FPS)** | 20~40 FPS (伴随长任务阻塞) | 稳定 60 FPS | **丝滑无感** |
| **内存常驻占用 (DOM Memory)** | 50MB ~ 80MB | 5MB ~ 10MB | **节省 85%+** |
